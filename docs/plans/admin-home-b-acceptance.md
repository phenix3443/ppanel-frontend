## 术语

- **运行状态项**：状态条中的整体健康徽标、服务器项和工单项。重启按钮是操作按钮，不属于运行状态项。
- **首屏**：页面加载完成后、尚未滚动（`scrollY = 0`）时视口内的区域。
- **成功空数据**：接口请求成功，并按该接口的有效响应形状返回空列表或 0。
- **请求失败**：接口返回错误，或经过现有重试后仍然失败。
- **真实零值**：接口成功返回的统计值本身为 0。

## 验收标准

1. Home 在深色主题下使用原稿定义的 token；`canvas`、`surface`、`surface-raised` 三档底色与设计截图一致。
2. 文字和状态色在其所在底色上的对比度不低于 4.5 : 1，深浅两套主题都要满足。
3. warning 和品牌橙色（signal）是两个不同的 token。待处理工单 > 0 时用 warning，不用 signal。
4. 服务器离线数 > 0 或待处理工单 > 0 时，对应的运行状态项出现在首屏内，并同时用文字、数量和颜色提示。服务器和工单数据都成功取得且都为 0 时，运行状态项不显示红色或黄色。重启按钮始终使用 danger 样式，不受本条约束。
   - 首屏按两组视口判定：桌面 1440 × 900，窄屏 390 × 844。异常输入为服务器在线 4 台、离线 2 台，可另加待处理工单 > 0。
   - 这两组视口就是已有证据实际使用的视口。本条不再追加其他高度标准，也不用其他高度去推翻按这两组视口取得的证据。
5. 各接口成功返回空数据时，每个图表和排行都显示空状态（虚线框和说明文字），不出现空白卡片或 NaN；0 台服务器时状态条显示「尚未接入服务器」。请求失败不属于本条，见第 10 条。
6. KPI 和排行数字使用等宽数字（`tabular-nums`）。
7. 可以切换到浅色主题，且浅色主题满足第 2 条。
8. token 只在 admin 应用内生效。`packages/ui/src/styles/globals.css` 由 user 端共用，不能通过修改其中的全局值影响 user 端。
9. 数据来源、跳转链接（在线用户和服务器 → `/dashboard/servers`，工单 → `/dashboard/ticket`）和系统重启流程保持不变。
10. 加载中、请求失败、成功空数据和真实零值四种状态要能区分：
    - 失败的模块显示失败文案，不显示 0、空状态、「运行正常」或「无待处理」，并保留重试或刷新途径。
    - 成功的模块照常显示真实结果，不因其他模块失败而被隐藏或改写。例如收入请求失败、工单成功返回 0 时，工单项仍可显示「无待处理」。
    - 只要有模块在加载或已失败，整体健康徽标就不能显示「系统运行正常」。
    - 不新增接口或后台能力。
11. 用键盘可以到达状态链接、统计切换、排行切换和重启按钮，并且有可见焦点。选中状态可被辅助技术识别（无障碍树中能读到选中项），图表提供可读取的数据说明。本条不指定读屏软件，VoiceOver 实测不是验收要求。
12. 在 1440px 和 390px 宽度下（视口同第 4 条）检查状态条、长名称和空状态：首屏异常项可读；长名称可以截断，但要能读到全名；数值完整显示；窄屏下没有页面级横向溢出。

## 取证方式

验收结果不绑定具体工具。具体步骤见技术方案 [admin-home-b.md](admin-home-b.md) 的「浏览器取证清单」。

- **当前做法：** 由 agent 用 `scripts/paperclip/browser.sh` 在宿主的 Playwright 容器中取证（Chromium、Firefox、WebKit），用 `viewport` 和 `colorScheme` 设置视口和主题。每项都记录浏览器及版本、主题、视口和截图，再由未参与实现的 Coder 独立核对。
- **历史规则：** 原稿第 170、197 行要求由 Board 在自己的 Mac 上取证，并且不派 agent 用浏览器。第 210 行写的「headless Chrome 窄屏截图不可信」，是原型阶段用 headless Chrome 截图时遇到的限制，不是普遍限制。这三处已被 2026-10-27 Board 的取证决定取代，原稿保留作为历史记录，不再作为执行要求。
- **受控数据的边界：** 用构造响应取得的证据，只能证明前端在这些响应下的行为，不能证明与测试后端真实联调，也不能证明测试集群健康。测试后端联调是否需要做，单独决定，不在本文件的 12 条之内。

## 可用性研究（后续可选，不是交付门禁）

原稿第 195–206 行规划的观察项目（任务耗时、第一次点击、误判）没有基线、样本量和通过阈值，所以不作为本次交付的门禁，只列为后续研究待办。真要做时，先定好基线、样本和阈值。做完之前，不声称 B 提高了效率或降低了误判。
